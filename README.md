# ThreadX_STM32H750XBHx

A comprehensive ThreadX-based firmware for the STM32H750XBHx microcontroller.  
The project demonstrates how to run the Azure RTOS stack (ThreadX, FileX, ~~NetX Duo~~, USBX) on ST's STM32H750 development board and includes an evolving I2C-based communication hub that dispatches commands to various peripherals.

## Prerequisites
- Docker (recommended) or host packages:
  - Arm GNU toolchain providing `arm-none-eabi-gcc`
  - CMake 3.20 or newer
  - Ninja build system
- [STM32CubeProgrammer](https://www.st.com/en/development-tools/stm32cubeprog.html) for flashing.

## Quick Start

The provided `Dockerfile` creates an Ubuntu image containing the Arm GNU toolchain, CMake, Ninja and the required STM32 and ThreadX sources.

1. **Build the Docker image**

   ```bash
   docker build -t threadx-h750 .
   ```

2. **Start the container and build**

   ```bash
   docker run --name threadx-h750-docker -it -p 2022:22 threadx-h750 bash
   ./build.sh Release   # inside the container
   ```
   The resulting ELF image will be placed in `build/Release/IOT_DUAL_STM32.elf`.

3. **Clean the build tree**

   ```bash
   make clean
   ```

## Flashing and Running

The firmware is linked for flash address `0x08000000`. Flash the ELF onto the board using STM32CubeProgrammer or a similar SWD utility:

```bash
STM32_Programmer_CLI -c port=SWD -d build/Release/IOT_DUAL_STM32.elf 
```

or just use stm32programmer choose elf to download

Connect a serial terminal to **UART5 @115200 8N1** to observe the `IOT-DUALMCU Booting Done.` banner printed at boot.

## Directory Layout

| Path | Description |
| ---- | ----------- |
| `Src/`, `Inc/` | Application sources and headers generated by STM32CubeMX |
| `cmake/` | CMake toolchain and helper modules |
| `docs/` | Additional documentation and design notes |
| `stm32-mw-*` | Middleware components such as ThreadX, FileX, NetX Duo and USBX |
